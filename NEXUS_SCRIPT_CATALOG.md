## 🤝 Contribution & Maintenance

### Adding New Scripts
```bash
# Create new script
cat > /home/user/scripts/new-script.sh << 'EOF'
#!/bin/bash
# New Script Description
# Author: Your Name
# Date: $(date)

echo "New script functionality"
EOF

# Make executable
chmod +x /home/user/scripts/new-script.sh

# Add to git
git add /home/user/scripts/new-script.sh
git commit -m "Add new-script.sh"
```

### Updating Documentation
```bash
# Create manual from template
cp SCRIPT_DOCUMENTATION_TEMPLATE.md NEW_SCRIPT_MANUAL.md

# Customize manual
nano NEW_SCRIPT_MANUAL.md

# Add to catalog
nano NEXUS_SCRIPT_CATALOG.md
```

### Documentation Workflow
1. **Identify** - Select script to document
2. **Analyze** - Understand script functionality
3. **Template** - Use documentation template
4. **Customize** - Fill in script-specific details
5. **Test** - Verify documentation accuracy
6. **Commit** - Add to version control
7. **Update Catalog** - Add to script catalog
